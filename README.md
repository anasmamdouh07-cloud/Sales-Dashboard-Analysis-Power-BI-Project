# Sales-Dashboard-Analysis-Power-BI-Project

Overview

This project presents an interactive Power BI Sales Dashboard designed to analyze multi-year sales performance (2020–2022), with a detailed focus on 2022 sales results, KPIs, regional performance, and target achievement.

The dashboard was developed to transform raw sales data into meaningful business insights that support data-driven decision-making.

---

Key Performance Indicators (2022)

KPI| Value
Total Sales| 4,048M
YTD Sales| 1,387M
Total Margin| 149K
Target Achievement| 92.7%
Sales Target| 1.50B

---

Business Insights

- November recorded the highest sales performance, reaching 487M.
- December experienced a decline in sales following the seasonal peak.
- The South region achieved the strongest sales performance with 1.46B in sales.
- Core Stores generated the highest sales contribution, led by Clothing products.
- The gap between actual performance and target achievement highlights opportunities for improvement across weaker periods and regions.

---

Dashboard Features

- Multi-year sales analysis (2020–2022)
- Year-to-Date (YTD) performance tracking
- Regional sales comparison
- Product category analysis
- Target vs Actual performance monitoring
- Interactive filtering and drill-down capabilities

Data Presentation Note

KPI values displayed in the dashboard are represented in Millions (M) and rounded for improved readability and visualization. Target calculations are represented in Billions (B).

Example:

- 1,387.66M = 1.38766B
